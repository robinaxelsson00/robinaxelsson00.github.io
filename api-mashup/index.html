Bundesliga Match- & Väder-Matchup

Hämtar aktuella matcher från Bundesliga via OpenLigaDB och matchar spelorten i realtid mot live väderdata från Open-Meteo API.

Kopplar upp mot API:er och sammanställer live väder...

Hur fungerar denna API-mashup?

1. OpenLigaDB API Anropas för att hämta live fotbollsdata från Bundesliga (lag, klubbmärken, spelort, datum och resultat).
2. Open-Meteo Weather API Kopplar hemmalagets stad till exakta koordinater (latitud/longitud) och hämtar temperatur, vind och väderlek i realtid för arenan.
