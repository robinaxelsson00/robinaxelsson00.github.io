3. Så fungerar scrapern (Kodarkitektur)

Scrapern körs asynkront med Node.js. För varje URL anropas sidan med anpassade HTTP-headers, varpå HTML-trädet läses in i Cheerio för att extrahera exakta CSS-klasser och fält. För att undvika att överbelasta målservern appliceras en inbyggd tidsfördröjning (delay()) mellan anropen innan datan konverteras till CSV-format. 

// Exempel: Selektorer och parsing med Cheerio
const $ = cheerio.load(html);

$('.SearchResultCard-card').each((index, element) => {
    const card = $(element);
    const name = card.find('h2').text().trim();
    const orgNr = card.find('.CardHeader-propertyList:contains("Org.nr")').text().replace('Org.nr', '').trim();
    const phone = card.find('.CardHeader-phone').text().replace('Telefon', '').trim();
    const address = card.find('.fa-location-dot').parent().text().trim();

    if (name) {
        companies.push({ name, orgNr, phone, address });
    }
});
